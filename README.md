# Personal Project Showcase App

## About the Project

The Personal Project Showcase App is a React-based web application that allows users to display, manage, and organize their software development projects in one place.

Users can dynamically add projects, search for specific projects, view project descriptions and images, and access project links.

## Features

- Add new projects dynamically.
- Search projects by title.
- Display projects using reusable project cards.
- Add project images and GitHub links.
- Delete projects with confirmation.
- Save projects using browser localStorage.
- Responsive user interface.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser localStorage

## Component Structure

The application uses the following React components:

- **App:** Main component that manages application state and coordinates other components.
- **Header:** Displays the application heading.
- **ProjectForm:** Allows users to add new projects.
- **SearchBar:** Allows users to search for projects.
- **ProjectList:** Displays the filtered projects and handles deletion.

## Installation and Setup

1. Clone the repository.
2. Navigate into the project folder.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local development URL displayed in your terminal.

## Production Build

To generate an optimized production build, run:

`npm run build`
